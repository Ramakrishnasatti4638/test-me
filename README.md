# Todo App

A lightweight, modern, responsive Todo web application built with vanilla HTML5, CSS3, and JavaScript.

## Features

- **Add Tasks**: Quickly add new tasks via the input form.
- **Toggle Completion**: Check off tasks as completed or mark them as active.
- **Filter Tasks**: Switch views between "All", "Active", and "Completed".
- **Delete Tasks**: Remove individual tasks with the delete button.
- **Clear Completed**: Conveniently batch clear completed tasks.
- **Persistence**: All tasks persist locally in the browser using `localStorage`.
- **Responsive & Accessible**: Clean design adapted for mobile and desktop screens with appropriate aria labels.
