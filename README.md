# Todo App

A simple, self-contained todo app built with plain HTML, CSS, and JavaScript. No build step or dependencies required.

## Features

- Add, complete, and delete todos
- Filter by All / Active / Completed
- "Clear completed" to remove finished items
- Live count of remaining items
- Persists todos in the browser via `localStorage`
- Responsive, accessible UI

## Files

- `index.html` — markup and app structure
- `styles.css` — styling
- `app.js` — application logic
