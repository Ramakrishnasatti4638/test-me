# Sample Store Frontend

A small React + TypeScript single-page app that lists products and shows
their details. It is a pure client — the product data comes from a
separate API whose base URL is read from `VITE_API_BASE_URL` (default
`http://localhost:8000`).

## Install

```bash
npm ci
```

## Run (development server)

```bash
npm run dev
```

## Test

```bash
npm test
```
