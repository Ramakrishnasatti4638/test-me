# Todo App

A simple, modern todo application built with vanilla HTML, CSS, and JavaScript.

## Features

- ✅ **Add todos** - Quickly add new tasks with the input field
- ✅ **Complete todos** - Mark tasks as done with the checkbox
- ✅ **Delete todos** - Remove tasks you no longer need
- ✅ **Filter todos** - View all, active, or completed tasks
- ✅ **Real-time statistics** - Track total, active, and completed todos
- ✅ **Persistent storage** - Todos are saved to localStorage
- ✅ **Responsive design** - Works great on desktop and mobile devices
- ✅ **Smooth animations** - Delightful UI with transitions and animations

## How to Use

1. Open `index.html` in your browser
2. Type a task in the input field and click "Add Todo" or press Enter
3. Check the checkbox to mark a task as complete
4. Click "Delete" to remove a task
5. Use the filter buttons to view all, active, or completed tasks

## Project Structure

- `index.html` - Main HTML structure
- `style.css` - Modern styling with gradient background and smooth animations
- `script.js` - Todo application logic with class-based architecture
- `README.md` - This file

## Technical Details

- **Storage**: Uses browser's localStorage API to persist todos across sessions
- **Architecture**: Class-based TodoApp with methods for CRUD operations
- **Design**: Gradient purple background with clean, modern UI
- **Responsive**: Mobile-friendly layout with media queries

## Browser Support

Works in all modern browsers that support:
- ES6 JavaScript
- localStorage API
- Flexbox and CSS Grid
