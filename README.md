# Simple Todo App

A lightweight, responsive, and accessible Todo application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Add Tasks**: Quickly create tasks with the input form.
- **Toggle Completion**: Mark tasks complete or active with styled checkboxes.
- **Filter**: Filter by "All", "Active", or "Completed" tasks.
- **Delete Tasks**: Remove individual tasks with a single click.
- **Clear Completed**: Conveniently batch delete finished tasks.
- **Persistence**: Automatically preserves todos in browser `localStorage`.
- **Responsive & Accessible**: Clean design adapted for mobile and desktop screens with keyboard accessibility and ARIA labels.

## Files

- `index.html`: Main markup structure and semantic layout.
- `styles.css`: Modern UI design using CSS variables and flexbox.
- `app.js`: State management, event handlers, and localStorage synchronization.
