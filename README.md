# Todo App

A simple, self-contained todo app built with vanilla HTML, CSS, and JavaScript. No build step, no dependencies.

## Features

- Add, complete, and delete todos
- Filter by All / Active / Completed
- Live count of remaining items
- Clear all completed at once
- Persists to `localStorage`, so todos survive page reloads

## Files

- `index.html` — markup
- `styles.css` — styling
- `app.js` — todo logic and persistence
