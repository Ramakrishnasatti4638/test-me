# Todo App

A simple, modern todo application built with vanilla HTML, CSS, and JavaScript.

## Features

- ✅ Add new todo items
- ✅ Mark todos as complete/incomplete
- ✅ Delete todo items
- ✅ Persistent storage using localStorage
- ✅ Real-time statistics (total and completed count)
- ✅ Responsive design
- ✅ Clean, modern UI with gradient background

## Usage

1. Open `index.html` in your web browser
2. Type a todo item in the input field
3. Click "Add" or press Enter to add the todo
4. Click the checkbox to mark a todo as complete
5. Click "Delete" to remove a todo
6. Your todos are automatically saved to your browser's local storage

## Files

- `index.html` - HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Todo app logic and interactivity

## Technologies Used

- Vanilla JavaScript (ES6+)
- HTML5
- CSS3 (Flexbox, Gradients)
- LocalStorage API
